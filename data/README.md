# nrib_moromi_42.json — 実バッチ醪データ（検証用）

## 出典
**酒類総合研究所（国税庁・NRIB）「清酒もろみの発酵経過及び製成酒成分」データベース**
https://nribjyo.nrib.go.jp/moromi/jitumoromis
（酒類醸造講習・清酒コースで実施した42仕込分。2026-07-14取得）

## 各仕込の共通条件
総米20kg／原料米60%山田錦／普通速醸酒母／純米酒。講習目的のため仕込条件は多様（＝ばらつきが大きい）。

## 収録項目（各仕込の要約ランドマーク）
`no`(仕込番号) `maxT`(最高品温℃) `maxB`(最高ボーメ) `days`(仕込日数) `alc`(アルコール分%) `nihon`(日本酒度) `sando`(酸度) `amino`(アミノ酸度) `kasu`(糟歩合%) `gluc`(グルコース残糖%) `yeast`(酵母種類・協会601〜1801号) `kapro`(カプロン酸エチル=りんご様吟醸香 mg/l) `isoac`(酢酸イソアミル=バナナ様 mg/l) `etac`(酢酸エチル) `isoal`(イソアミルアルコール)

※ 時系列（品温/ボーメ/アル/酸の日ごと）はDB上グラフ画像のみで数値非公開のため、要約値を収録。

## 用途・検証結果（§8.10）
醪モデルの出力レンジ・相関の検証。出力は実分布内、相関も符号一致（残糖×日本酒度 r=−0.80／酵母→吟醸香 吟醸系4.60 vs 普通0.95（純株のみ、2026-09-05 再計算））。

## 参考文献（時系列・関係の検証）
- 三重県工業研究所報告 No.44(2020) AB直線 → 醪の(アル,ボーメ)は直線・終点(16.5%,0)。モデルは R²=0.95 で再現。
- 分析化学 64(7),527(2015) 清酒もろみの経時測定（四段16日/アル添19日の実仕込）
- NRIB「モデルもろみによる清酒発酵の解析」（ブドウ糖0.5〜5%で発酵速度ほぼ一定＝Km低い）

## 記録簿（log.html）の「実測の目安」（2026-09-28）
記録簿の比較線を、モデルの計算（旧「標準カーブ」＝仕様書v2.0凍結エンジン。上槽時ボーメ−2〜−4に落ちていた）から、
`nrib_moromi_42_full.json` の実測に置き換えた。生成は `build_log_reference.py`（log.html の `NRIB_REF` ブロックを書き換える）。
- 対象：42件から異常4件（no.5・6・9・37。§8.10 の正常クラスタ38仕込と同じ除外）を除いた**38件**
- 代表値＝中央値、幅＝四分位（線形補間・R type7）と最小〜最大
- DBは日ごとの経過をグラフ画像でしか出していない（2026-09-28 仕込番号1で再確認：`/images/tmp/bome.png` 等の画像のみ）ため、
  **日ごとの線は作らず**、次の3節目だけを出す。節目どうしは結ばない（補間・外挿しない）
  1. 最高ボーメ `maxB`（中央7.55・四分位6.91〜7.97・5.92〜9.6）…日付は非公開。赤本 p.265「留後3〜4日目…最高のボーメ」の位置に置く
  2. 最高品温 `maxT`（中央14.0・四分位13.2〜14.9・12.4〜16.4℃）…日付は非公開。赤本 p.263「醪日数の3分の1で最高温度、3分の2まで持続」→醪日数中央20日の6.7〜13.3日目に置く
  3. 上槽時ボーメ＝−`nihon`/10（中央0.00・四分位−0.14〜+0.29・−0.94〜+1.74）…x は各仕込の `days`（15〜21日）。換算は赤本 p.270（日本酒度−20↔ボーメ2）
